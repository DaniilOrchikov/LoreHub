# LoreHub

Простое веб-приложение для разработки лора вселенной (игровой или книжной).

## Что умеет

- Создавать **документы** (персонаж, раса, локация, история и т.д.).
- Создавать **связи** между документами (например, `раса → представитель`, `муж → жена`).
- Добавлять **события**, привязанные к документу:
  - с датой начала;
  - и опциональной датой завершения;
  - если дата завершения не указана, событие считается мгновенным.
- Работать с отдельной вкладкой **Таймлайн**:
  - добавлять на один таймлайн отдельные события;
  - добавлять все события выбранного документа;
  - комбинировать события из разных документов;
  - менять порядок событий перетаскиванием;
  - смотреть визуализацию начала/окончания события на шкале;
  - переключать масштаб шкалы: день, месяц, год;
  - видеть подписи шкалы (дни/месяцы/годы в зависимости от масштаба);
  - прокручивать шкалу по горизонтали (скролл + кнопки ←/→).

## Запуск

Так как это статическое приложение, достаточно открыть `index.html` в браузере.

Для локального сервера можно использовать:

```bash
python3 -m http.server 8080
```

После этого приложение будет доступно по адресу `http://localhost:8080`.

## Хранение данных

Данные сохраняются в `localStorage` браузера под ключом `lorehub-data-v2`.
