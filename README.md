# LoreHub

Веб-приложение для разработки лора вселенной (игровой или книжной).

## Возможности

- **Документы**: персонажи, расы, локации, истории и другие сущности.
- **Связи**: связь между двумя документами (`муж`, `жена`, `представитель`, `союзник` и т.д.).
- **События**: события, привязанные к документу, с датой начала и опциональной датой завершения.
  - Если дата завершения не указана, событие считается мгновенным.
- **Отдельная вкладка таймлайна**:
  - меню добавления одного события;
  - меню добавления всех событий выбранного документа;
  - на одном таймлайне можно смешивать события из разных документов;
  - перетаскивание событий вверх/вниз для ручной перестановки;
  - временная шкала справа с точкой старта, линией длительности и точкой завершения;
  - масштаб шкалы: **день / месяц / год**.

## Запуск

Откройте `index.html` в браузере
или запустите локальный сервер:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Хранение данных

Данные сохраняются в `localStorage` под ключом `lorehub-data-v2`.
