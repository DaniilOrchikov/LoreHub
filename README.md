# LoreHub

LoreHub — простое SPA-приложение для разработки лора вселенной (игровой или книжной).

## Что можно делать

- Создавать **документы** (персонажи, расы, события, локации, истории и другое).
- Добавлять **связи** между документами (например, `раса → представитель`, `муж → жена`).
- Добавлять **события**, привязанные к конкретному документу:
  - с началом и завершением;
  - или мгновенные (если завершение не указано, берется время начала).
- Строить **таймлайн**:
  - по всем событиям;
  - или только по выбранным документам.

## Запуск

Откройте файл `index.html` в браузере.

Данные сохраняются локально в `localStorage` браузера.
